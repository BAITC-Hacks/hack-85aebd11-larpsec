# Проверка реализации

Проверено 23 сентября 2026 года, Python 3.14.7, зависимости из `backend/uv.lock`.

- `uv run --frozen pytest -q`: **38 passed**.
- `uv run --frozen ruff check app tests scripts`: **All checks passed**.
- `./backend/run.sh`: сервер запустился на `127.0.0.1:8000`.
- Учебный сценарий выполнен через настоящий HTTP API: загрузка двух DOCX, запуск,
  опрос состояния, получение результата и Markdown-отчёта.
- Найдены ожидаемые переименование, перенос, потенциальная потеря, дублирование,
  конфликт и новый отдел. Контрольные случаи с разными областями ответственности
  и двойным подчинением не создают ложных замечаний в учебном примере.
- Проверены существование цитат, запрет ссылки только на общий заголовок вместо действия,
  сохранение отрицания в отчёте, неполнота PDF со сканом и текстовым колонтитулом,
  переносы строк и табуляция Word, обработка неполного извлечения моделью.
- Предоставленное положение редакции № 8 прочитано локально: 492 фрагмента,
  83993 символа. Пустой пункт 5.5.3 отмечен предупреждением. Исходник не включён в Git.

Адаптер Responses API проверен с тестовым HTTP-провайдером, включая корректный ответ,
отказ, неполный ответ, неверную схему, поддельную цитату, таймаут, отказ в доступе
и повтор запроса после временной ошибки. **Живые вызовы модели не выполнялись:**
для них нужно настроить ключ и имя модели и отдельно оценить качество на документах.
