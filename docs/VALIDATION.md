## Ограничения проверки

Адаптер Responses API проверен с тестовым HTTP-провайдером, включая корректный ответ,
отказ, неполный ответ, неверную схему, поддельную цитату, таймаут, отказ в доступе
и повтор запроса после временной ошибки. **Живые вызовы модели не выполнялись:**
для них нужно настроить ключ и имя модели и отдельно оценить качество на документах.

Docker-сборка не запускалась: Docker отсутствует в рабочем окружении.
Тестовый клиент Starlette выдаёт предупреждение об устаревании поддержки httpx;
это предупреждение зависимости, тесты успешно завершаются.
