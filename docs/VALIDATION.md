## Ограничения проверки

`demo` остаётся анализом по правилам. Свободные перефразирования и сложные конфликты
не имеют гарантии распознавания. Необязательное расширение конфликта между должностью
и подразделением через доказанную связь полномочий не реализовано; проверяются
конфликты одного владельца с совпадающим действием и областью.

Responses API проверен с тестовым HTTP-провайдером: структурированный ответ, отказ,
неполный ответ, неверная схема, поддельная цитата, таймаут, отказ в доступе и повтор
после временной ошибки. **Живые вызовы модели не выполнялись**. OCR не добавлен.

Docker-сборка не запускалась: Docker отсутствует в рабочем окружении.
Тестовый клиент Starlette выдаёт предупреждение об устаревании поддержки httpx;
оно не приводит к падению тестов.

Прежние завершённые сравнения не пересчитываются автоматически. Для проверки нового
извлечения создайте новое сравнение и заново загрузите исходные документы.
